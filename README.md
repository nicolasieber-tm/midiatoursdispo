# Midia Tours Dispo-Assistent, Konzeptvorschau

Interaktive Vorschau eines internen Anfrage- und Kalkulationstools (Anfrage, Fahrzeugvorschlag, Kalkulation, Offerte, Bexio).

- `index.html`: die komplette Vorschau, keine Abhängigkeiten
- `server.js`: minimaler statischer Server für Railway (`npm start`)

Lokal testen: `node server.js` und http://localhost:3000 öffnen.
